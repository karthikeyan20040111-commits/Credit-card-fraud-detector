ABSTRACT


The proliferation of digital transactions and online banking has emerged as a critical societal challenge in the modern financial age due to the exponential rise in credit card fraud. This project presents a comprehensive AI-driven FraudGuard System that integrates modern web technologies and heuristic machine learning simulations to automatically detect fraudulent transactions and identify suspicious behavioral patterns. The system employs heuristic rule engines mimicking Random Forest and XGBoost algorithms combined with sophisticated data processing pipelines to extract, analyze, and authenticate financial transactions through multiple parallel detection mechanisms.

The proposed system implements a complete pipeline architecture that processes real-time transaction data through sequential stages of validation, parameter extraction, risk assessment, confidence scoring, and Explainable AI (SHAP) analysis. The backend infrastructure utilizes Next.js API Routes for efficient bridging, while the frontend leverages React, Tailwind CSS, and Recharts for dynamic data visualization. The system generates comprehensive analytics including transaction volume charts, SHAP-based impact assessments, and risk indexes, presented through an interactive and highly responsive glassmorphic dashboard interface.

DEFINITIONS


1. Fraud Detection
The process of extracting meaningful patterns from transactional data to identify anomalous or suspicious behavior indicative of fraud.


2. Explainable AI (SHAP)
Explainable AI refers to methods that help understand and interpret machine learning models. SHAP specifically breaks down the black-box models to show the exact weight each feature had on the final score.


3. Transaction Velocity
A metric tracking the frequency of transactions associated with a user or account within a given 24-hour time window.


4. Heuristic Rule Engine
An implementation of decision rules mimicking complex ML algorithms by evaluating inputs such as amount, location, and time to generate dynamic confidence scores.


5. Glassmorphism
A UI design trend characterized by translucent, blurred backgrounds with subtle borders to give the illusion of frosted glass.

1. INTRODUCTION

1.1 SYSTEM OVERVIEW

The FraudGuard AI System is an intelligent software platform designed to analyze financial transactions and identify potentially fraudulent activities using advanced simulated artificial intelligence techniques. The system integrates real-time web processing, data visualization, and heuristic machine learning rules to examine different attributes of a transaction. By processing geographical, monetary, and temporal information, the system provides a comprehensive analysis that helps determine the authenticity of a financial event.

The system works by allowing users and administrators to monitor transactions through a web-based interface developed using the Next.js App Router framework. Once a transaction is processed, the system performs several automated tasks including validation, metadata extraction, risk index calculation, and SHAP-based feature importance breakdown. Parameters such as location risk, transaction amount size, and 24-hour velocity are evaluated to output a confidence score ranging from 0-99%.

1.2 OBJECTIVE

The main objective of the FraudGuard AI System is to develop an intelligent system capable of automatically analyzing transaction streams and identifying fraudulent behavior using modern technological stacks. The project aims to examine various components of a transaction to ensure accurate detection of compromised accounts or stolen credit cards.

The system performs transaction assessment by evaluating factors such as high monetary values, unusual hours, and high-risk geographical locations. Another objective is to implement an Explainability Panel (SHAP) to convert the "black box" prediction into understandable human insights. Additionally, the project focuses on generating automated reports that summarize analytical results, total fraud detected, and safe transactions processed.

3

These reports help users clearly understand the analytics without needing technical expertise. Another objective is to design a user-friendly, glassmorphic web interface using React and Tailwind CSS, allowing administrators to easily track live data and view analysis results through an interactive dashboard.

Finally, the project seeks to improve the accuracy, efficiency, and reliability of fraud detection systems by combining modern frontend frameworks, real-time data handling, and simulated machine learning technologies. By integrating multiple analysis techniques into a single platform, the system provides a comprehensive solution for digital security.

1.3 SYSTEM STUDY

1.3.1 Existing System

The existing systems for transaction verification and fraud content detection mainly rely on manual analysis or limited automated legacy rules. In many cases, compliance teams must manually inspect transaction logs to determine whether the activity is authentic or manipulated. This process is time-consuming, inefficient, and often inaccurate, especially when dealing with a large volume of global transactions across banking platforms. Traditional systems typically focus on only one aspect of analysis, such as pure amount limits or basic geolocation blocking, without combining multiple nuanced techniques.

Some currently available tools use basic rules to detect fraud, but these systems often have limitations in scalability and explainability. Many existing solutions flag transactions without informing the user *why* it was flagged, lacking transparency. Additionally, these systems may not perform detailed velocity assessment, which makes it difficult to detect subtle manipulations such as repeated small transactions indicative of bot activity.

4

Another limitation of existing systems is the lack of integrated platforms that combine live dashboards, real-time SHAP explainability, alert engines, and model retraining interfaces in a single framework.

1.3.2 Literature Survey

The rapid growth of digital banking has increased the threat of compromised cards, creating serious challenges for verifying the authenticity of financial actions. Researchers have proposed various artificial intelligence and machine learning techniques to detect fraud. Many studies focus on using Random Forest and XGBoost algorithms to analyze behavioral inconsistencies. Deep learning models have been widely used to detect complex manipulation patterns that indicate tampering.

Advantages of Modern Methods:

  • Machine learning and deep learning algorithms improve detection accuracy compared to manual verification.
  • Advanced visualization techniques allow systems to analyze temporal patterns effectively.
  • Explainable AI (XAI) technologies help convert model outputs into understandable human text for further analysis.
  • Automated systems can process large volumes of transactional data efficiently with low latency.

Disadvantages of Legacy Methods:

  • Many legacy systems focus only on simple thresholds and ignore complex feature interactions.
  • Lack of real-time alert overlay interfaces for administrators.
  • Inability to seamlessly provide "black-box" breakdown (SHAP) directly in the user UI.
5

Another area of research focuses on Explainable AI (XAI) for interpreting model behavior. Presenting SHAP values helps administrators trust the system's output. Despite these advancements, many existing studies focus only on backend metrics. Few systems combine real-time visualization, explainability, alert notification, and reporting in a unified Next.js platform. Therefore, the proposed FraudGuard AI System aims to integrate these techniques to improve the reliability and efficiency of fraud detection user interfaces.

1.3.3 Proposed System

The proposed FraudGuard AI System is designed to provide an intelligent and automated solution for analyzing transactions and identifying fraudulent activities. The system integrates modern web architecture, data visualization libraries, and heuristic rule engines to perform comprehensive analysis of transaction metadata.

In the proposed system, administrators access a web-based dashboard developed using the Next.js App Router and React. Once a transaction is processed, the system evaluates different parameters such as transaction amount, geographic location risk, time of day, and 24-hour velocity. The system calculates a dynamic confidence score using a simulated Random Forest/XGBoost heuristic engine.

The system also extracts the features to populate a SHAP Explainability Panel, clearly showing the positive or negative impact of each variable on the final decision. High-risk transactions trigger the Smart Alert Engine, creating localized notifications for immediate attention. Finally, the system includes a Report Generator for exporting CSV/JSON compliance logs, and a simulated Model Retraining pipeline for continuous learning workflows.

2. SOFTWARE REQUIREMENTS SPECIFICATION

2.1 EXTERNAL INTERFACE REQUIREMENTS

2.1.1 User Interfaces

The FraudGuard AI System provides a user-friendly web interface that allows users to interact with the system easily. The interface is designed using modern web technologies such as React and Tailwind CSS (v4) with custom glassmorphism aesthetics to ensure a responsive and visually appealing premium design. Through the user interface, administrators can monitor live traffic, initiate manual transaction analysis, and view detailed XAI results.

The system includes several interface pages such as the live analytics dashboard, transaction checker, alert panel, and report generator. The live dashboard utilizes `recharts` to render dynamic Area, Bar, and Pie charts that update asynchronously.

Dashboard Interface

  • Acts as the central control panel for monitoring overall system health.
  • Displays system statistics such as total safe transactions, total fraud detected, and current Risk Index.
  • Provides navigation to different system modules via a dark-navy sidebar.

Transaction Analyzer Interface

  • Allows manual entry of transaction parameters (Amount, Location, Time, Velocity).
  • Provides a simple analyze button for initiating the heuristic risk assessment.
  • Displays the final Fraud Confidence Score and visual SHAP impact bars.

2.1.2 Hardware Requirements

• User-End Devices:

Administrators can access the system using laptops, desktops, or tablets with minimum specifications of a modern dual-core processor and 4 GB RAM, running an updated web browser (Chrome/Edge/Firefox) supporting modern JavaScript and CSS grid/flexbox.

• Backend Servers:

The system requires a Node.js hosting environment (such as Vercel or a traditional VPS) with multi-core processors, capable of running Next.js serverless API routes efficiently.

2.1.3 Software Interfaces

Next.js Framework: High-level React framework used to build the application. It handles routing, server-side rendering, and provides the API infrastructure for transaction processing.

React Library: The core UI library used for building interactive, state-driven components like dashboards and modals.

Tailwind CSS: A utility-first CSS framework used for rapid, responsive styling and implementing the glassmorphic aesthetic.

Recharts: A composable charting library built on React components used for all data visualization (AreaChart, PieChart, BarChart).

3. SOFTWARE DESIGN

3.1 ARCHITECTURAL DESIGN

The FraudGuard AI System employs a modern client-server architecture nested within the Next.js App Router paradigm. This integrates frontend rendering interfaces, backend API routes, and a simulated inference engine to provide reliable detection of manipulated or fraudulent transactions.

The architecture ensures scalability, responsiveness, and secure handling of data. The system is organized into major layers: User Interface Components (React), State Management (React Hooks Context), API Layer (Next.js `/api/transactions`), and the Heuristic Rule Engine (simulating ML logic).

3.2 DECOMPOSITION DESCRIPTION

3.2.1 AI-Based Transaction Analysis

This module is the core functionality, enabling automated calculation of a transaction's risk. The engine evaluates attributes based on high-risk geographic zones, suspicious monetary ranges, and high-velocity transactional frequency. Outputs are fed directly into the SHAP visualizer.

3.2.2 Smart Alert Engine

An asynchronous notification component that constantly polls for severe security breaches. It generates pulsing UI toast notifications for Critical and Medium alerts, storing a history log for administrator review and dismissal.

12

3.3 COMPONENT DESIGN

The system comprises specialized React components. The AnalyticsChart.tsx manages data fetching and rendering of Recharts. The TransactionChecker.tsx handles form input validation for manual checks. The ExplainabilityPanel.tsx takes the output scores and calculates visual bar widths for feature importance display.

3.4 DATA DESIGN

Data is currently managed through simulated continuous endpoints and structured JSON payloads. The Transaction Metadata includes Amount, Location, User ID, Timestamp, and Velocity. Responses from the API contain the Risk Score, Flag Status, and a list of identified Risk Factors. Future scalability allows these endpoints to connect directly to PostgreSQL databases and Python ML Microservices.

6. RESULTS AND OBSERVATIONS

The FraudGuard AI Dashboard successfully processed simulated high-frequency transaction data, rendering real-time analytics without frontend lag. The glassmorphism design provided a premium, authoritative feel suitable for enterprise financial security. The SHAP explainability panel successfully demystified the risk scores, allowing administrators to instantly understand the reasoning behind blocked transactions.
